#Data Coven — Data Engineering Portfolio

A collection of personal data engineering projects developed to explore Python-based ETL pipelines, workflow orchestration, cloud infrastructure and automated deployment.

The projects were built as practical exercises in designing and implementing data solutions across different technologies and environments.

Technologies
Python: Data ingestion, transformation and automation
Apache Airflow: Workflow orchestration and scheduling
PostgreSQL: Relational data storage
Google Cloud Platform: Cloud infrastructure and BigQuery
AWS and Azure: Experimentation with alternative cloud platforms
Linux and Bash: Environment configuration and automation
GitHub Actions: CI/CD workflows
Docker: Containerised development environments
Projects
ECB Exchange Rate Pipeline

A Python-based ETL pipeline that retrieves foreign exchange reference rates published by the European Central Bank.

The project explores the complete process of obtaining external data, validating and transforming it, and loading the results into a database.

Key features include:

Retrieving and processing exchange-rate data.
Transforming source data into a consistent structure.
Loading data into PostgreSQL.
Handling duplicate records and maintaining data integrity.
Automating pipeline execution.
Exploring deployments across GCP, AWS and Azure.
Apache Airflow Orchestration

An exploration of Apache Airflow for scheduling and managing data engineering workflows.

Includes examples of:

DAG development.
Task dependencies.
Scheduled pipeline execution.
Python-based processing tasks.
Local containerised Airflow environments.
Cloud Infrastructure and Automation

Experiments with provisioning and operating data processing environments across cloud providers.

Areas explored include:

Linux virtual machines.
Database connectivity.
Cloud storage.
Scheduled execution.
Environment configuration.
Deployment automation.
Engineering Approach

These projects reflect my interest in building complete data solutions rather than isolated scripts.

My focus has been on understanding how ingestion, transformation, storage, orchestration and deployment fit together, while developing maintainable and reusable Python code.
